EKF 扩展卡尔曼滤波：当机器人世界不再是直线

上一篇笔记里，我们从一辆只会直线运动的小车出发，学习了标准卡尔曼滤波 KF。

这一篇继续往前走：当机器人系统不再是线性的，卡尔曼滤波要怎样通过局部线性化扩展到 EKF。

标准 KF 的核心流程很清楚：

但是标准 KF 有一个前提：

系统模型和观测模型最好是线性的。

比如上一篇中的一维小车：

\[p_k = p_{k-1} + v_{k-1}\Delta t\]

这种关系很规整，用矩阵一乘就能描述。

可是真实机器人世界并没有这么老实。

机器人会转弯，姿态会变化，LiDAR 点会被旋转和平移，相机会把三维点投影到二维图像上，IMU 积分还牵扯到重力和旋转。

这些东西大多都是非线性的。

所以问题来了：

如果系统不再是线性的，卡尔曼滤波还能不能用？

答案是：能。

但要稍微“拐个弯”。

这个拐弯后的版本，就是 EKF，Extended Kalman Filter，扩展卡尔曼滤波。

1. 标准 KF 为什么不够用了？

标准 KF 喜欢这种形式：

\[x_k = F x_{k-1} + w\]
\[z_k = Hx_k + v\]

这里的 \(F\) 和 \(H\) 都是矩阵。

意思是：

这对一维小车很友好。

比如：

\[x = \begin{bmatrix} p \\ v \end{bmatrix}\]
\[F = \begin{bmatrix} 1 & \Delta t \\ 0 & 1 \end{bmatrix}\]

这样就能预测位置和速度。

但是机器人真正运动起来后，就没这么简单了。

比如一个二维移动机器人，它的状态可能是：

\[x = \begin{bmatrix} p_x \\ p_y \\ \theta \end{bmatrix}\]

其中：

如果机器人以速度 \(v\)、角速度 \(\omega\) 运动，那么下一时刻位置可能是：

\[p_x' = p_x + v\Delta t \cos\theta\]
\[p_y' = p_y + v\Delta t \sin\theta\]
\[\theta' = \theta + \omega\Delta t\]

这里出现了：

\[\cos\theta\]
\[\sin\theta\]

这就不是简单的矩阵乘法了。

也就是说：

机器人一转弯，标准 KF 就开始不太舒服。

不是标准 KF 不努力，而是它原本就擅长线性系统。
你让它直接处理非线性问题，就像让直尺去量弯路，能量，但不太优雅。

可以先把标准 KF 和真实机器人系统放在一起看，区别会更直观：

从图 1 可以看出，最关键的区别是：

所以 EKF 不是推翻 KF，而是把 KF 扩展到非线性系统中。

2. EKF 的核心思想：局部线性化

EKF 的核心思想可以用一句话解释：

非线性函数整体不好处理，那就在当前估计点附近，把它近似成线性的。

这句话听起来有点数学，但直觉非常简单。

假设有一条弯曲的路。

你不能用一把直尺一次性量完整条弯路。
但如果你只看当前脚下附近很短的一段，这一小段弯路看起来就比较像直线。

EKF 就是这么干的。

它不会奢望把整个非线性函数一次性变成线性的。
它只在当前估计点附近做一个局部近似。

这个过程叫：

更具体一点，就是：

在当前状态估计附近，用一阶泰勒展开，把非线性函数近似成线性函数。

这就是 EKF 里的“扩展”。

它把标准 KF 的线性模型：

\[x_k = Fx_{k-1}\]

扩展成非线性模型：

\[x_k = f(x_{k-1}, u_k)\]

然后在当前点附近再用雅可比矩阵把它近似成线性的。

这件事可以用图 2 表示：整条曲线不好直接处理，但在当前估计点附近，可以先用切线做一个局部近似。

图 2 可以这样理解：

EKF 不是说世界突然变线性了，而是说在当前估计附近，先凑合把它当线性处理。

这个“凑合”不是敷衍，而是有数学依据的一阶近似。
只要估计点离真实值不是太远，局部线性化通常就能工作得不错。

但如果初始估计偏得太离谱，那局部近似也可能失效。

这也解释了为什么很多 EKF 系统比较依赖初值。

3. 从 F、H 到 f、h

标准 KF 里有两个重要矩阵：

到了 EKF，这两个矩阵对应的模型变成了非线性函数：

标准 KF：

\[x_k = F x_{k-1}\]
\[z_k = Hx_k\]

EKF：

\[x_k = f(x_{k-1}, u_k)\]
\[z_k = h(x_k)\]

这里：

比如二维机器人运动模型：

\[p_x' = p_x + v\Delta t \cos\theta\]
\[p_y' = p_y + v\Delta t \sin\theta\]
\[\theta' = \theta + \omega\Delta t\]

这个整体就可以写成：

\[x_k = f(x_{k-1}, u_k)\]

这里的 \(f\) 不是一个矩阵，而是一组非线性函数。

4. 雅可比矩阵是什么？

EKF 里经常会出现一个词：

雅可比矩阵。

这个名字看起来很有压迫感，但先不用怕。

雅可比矩阵可以先理解成：

当前状态稍微变一点，函数输出会跟着变多少。

比如机器人状态里有：

如果朝向 \(\theta\) 改变一点点，那么机器人下一步预测位置会跟着变化多少？

如果位置 \(x\) 改变一点点，那么传感器观测会变化多少？

这些“变化关系”，就是雅可比矩阵要描述的东西。

更数学一点说，如果有非线性函数：

\[f(x)\]

那么它在当前估计点附近的雅可比就是：

\[F = \frac{\partial f}{\partial x}\]

如果有观测函数：

\[h(x)\]

那么它的雅可比就是：

\[H = \frac{\partial h}{\partial x}\]

注意，这里的 \(F\)、\(H\) 和标准 KF 里的 \(F\)、\(H\) 形式上很像，但含义有一点区别：

所以 EKF 里的 \(F\)、\(H\) 往往会随着当前状态变化而变化。

这点非常重要。

把状态模型和观测模型放在一起看，雅可比矩阵在 EKF 里的位置就很清楚了：

图 3 里有一个很关键的点：

EKF 预测状态时用的是非线性函数 \(f\)，但传播不确定性时用的是 \(f\) 的雅可比 \(F\)。

同样：

EKF 预测观测时用的是非线性函数 \(h\)，但计算增益时用的是 \(h\) 的雅可比 \(H\)。

这就是 EKF 和标准 KF 的核心区别之一。

5. EKF 的预测阶段

标准 KF 的状态预测是：

\[\hat{x}_k = F x_{k-1}\]

EKF 的状态预测变成：

\[\hat{x}_k = f(x_{k-1}, u_k)\]

也就是说，状态本身用非线性函数直接预测。

比如二维机器人：

\[\hat{p}_x = p_x + v\Delta t \cos\theta\]
\[\hat{p}_y = p_y + v\Delta t \sin\theta\]
\[\hat{\theta} = \theta + \omega\Delta t\]

这一步不再强行写成矩阵乘法，而是直接按照真实的非线性运动模型算。

但是，协方差预测仍然需要类似标准 KF 的形式：

\[\hat{P}_k = F_k P_{k-1} F_k^T + Q\]

这里的 \(F_k\) 不是固定状态转移矩阵，而是：

\[F_k = \frac{\partial f}{\partial x}\]

也就是运动模型 \(f\) 对状态 \(x\) 的雅可比矩阵。

所以 EKF 预测阶段可以总结成：

这就像开车转弯：

真正走的时候按弯路走，但估计误差扩散时，在当前点附近用一条切线近似一下。

6. EKF 的更新阶段

标准 KF 的观测预测是：

\[H\hat{x}_k\]

EKF 的观测预测变成：

\[h(\hat{x}_k)\]

也就是说：

先把预测状态代入非线性观测函数，算出传感器理论上应该看到什么。

残差变成：

\[y_k = z_k - h(\hat{x}_k)\]

这里：

然后计算卡尔曼增益时，需要观测函数的雅可比：

\[H_k = \frac{\partial h}{\partial x}\]

卡尔曼增益为：

\[K_k = \hat{P}_k H_k^T(H_k\hat{P}_kH_k^T + R)^{-1}\]

状态更新：

\[x_k = \hat{x}_k + K_k y_k\]

协方差更新：

\[P_k = (I - K_kH_k)\hat{P}_k\]

EKF 并不是换了一套全新的滤波框架，而是在标准 KF 的流程中，把线性模型换成非线性模型，再用雅可比矩阵做局部线性化。

所以从流程上看，EKF 和 KF 很像。
但从模型上看，EKF 能处理更复杂的非线性机器人问题。

8. EKF 为什么还叫“卡尔曼滤波”？

虽然 EKF 引入了非线性函数和雅可比，但它仍然保留了卡尔曼滤波的基本结构。

它仍然有：

只是标准 KF 里的线性模型：

\[F, H\]

变成了非线性函数：

\[f, h\]

以及它们在当前估计点附近的雅可比：

\[F_k, H_k\]

所以 EKF 可以理解成：

标准 KF 的非线性版本。

它不是把非线性问题完全精确解决，而是采用局部线性近似，让卡尔曼滤波可以继续工作。

9. EKF 的完整流程

现在我们把 EKF 的一轮流程串起来。

预测阶段

状态预测：

\[\hat{x}_k = f(x_{k-1}, u_k)\]

计算运动模型雅可比：

\[F_k = \frac{\partial f}{\partial x}\]

协方差预测：

\[\hat{P}_k = F_k P_{k-1}F_k^T + Q\]

更新阶段

预测观测：

\[\hat{z}_k = h(\hat{x}_k)\]

残差：

\[y_k = z_k - \hat{z}_k\]

计算观测模型雅可比：

\[H_k = \frac{\partial h}{\partial x}\]

卡尔曼增益：

\[K_k = \hat{P}_kH_k^T(H_k\hat{P}_kH_k^T + R)^{-1}\]

状态更新：

\[x_k = \hat{x}_k + K_ky_k\]

协方差更新：

\[P_k = (I - K_kH_k)\hat{P}_k\]

这些公式看起来比标准 KF 多了一点，但本质仍然是：

用非线性模型预测，再用局部线性化后的卡尔曼更新修正。

把前面的预测、雅可比、残差和更新全部串起来，就是 EKF 的一轮完整流程：

图 5 和上一篇标准 KF 的流程很像。

区别在于：

你可以把 EKF 记成：

非线性预测 + 雅可比线性化 + 卡尔曼更新。

10. EKF 在机器人里常见在哪里？

EKF 在机器人领域非常常见，尤其是在状态估计和传感器融合中。

比如：

10.1 轮速计 + IMU 融合

移动机器人可以用轮速计估计位移，用 IMU 估计姿态变化。

但机器人运动模型涉及角度：

\[\cos\theta, \sin\theta\]

所以常常需要 EKF 处理。

10.2 GPS + IMU 融合

室外机器人、无人车、无人机中，经常会用 GPS 提供位置观测，用 IMU 做高频预测。

IMU 的状态传播涉及姿态、速度、重力等，也经常是非线性的。

10.3 视觉 SLAM / VIO

相机观测模型一般是投影模型：

这个投影过程是非线性的。

所以视觉惯性里程计中会经常出现 EKF 或 EKF 的变体，比如 MSCKF。

10.4 LiDAR-IMU 系统

LiDAR 点云和地图匹配时，点的位置和机器人位姿之间有旋转和平移关系。

比如一个点从 LiDAR 坐标系变换到地图坐标系：

\[p_w = Rp_l + t\]

这里 \(R\) 是旋转矩阵，涉及姿态变化，本身就在非线性空间里。

所以 LiDAR-IMU 系统里，通常不会只用最普通的 KF，而会使用 ESKF、IEKF 或 IESKF 这类更适合姿态和 IMU 的滤波形式。

后面讲 FAST-LIO2 的时候，我们会专门聊这个。

12. EKF 的局限性

EKF 很经典，也很常用，但它确实有局限。

12.1 线性化误差

EKF 使用一阶泰勒展开。

也就是说，它只保留了非线性函数在当前点附近的一阶变化。

如果函数弯得很厉害，或者当前估计点离真实值很远，那么一阶近似就可能不够准确。

这就像你拿切线去近似曲线。
离切点很近时，近似效果不错；
离得太远时，切线和曲线可能已经各走各的路了。

12.2 初值敏感

因为 EKF 是在当前估计点附近线性化，所以当前估计点很重要。

如果初始状态偏差太大，线性化点就会偏。
线性化点一偏，雅可比也会偏。
雅可比一偏，更新方向可能就不对。

这时候 EKF 可能不是慢慢变好，而是越修越歪。

12.3 雅可比容易推错

EKF 需要计算雅可比矩阵。

在简单模型里还好。
但在机器人系统里，状态维度一高，坐标变换一多，雅可比就容易写错。

尤其是涉及姿态、李群、IMU bias、外参时，手推雅可比非常考验耐心。

有时候程序不稳定，不一定是算法思想错了，可能只是雅可比某个符号写反了。

13. EKF 和后面 ESKF 的关系

学完 EKF 后，下一步就很自然地要看 ESKF。

因为 EKF 已经能处理非线性系统了，但在机器人里还有一个更麻烦的问题：

姿态不是普通向量。

位置可以直接加：

\[p' = p + \Delta p\]

但旋转不能简单地写成：

\[R' = R + \Delta R\]

这在三维机器人、IMU、LiDAR-IMU 系统里非常关键。

所以后面很多机器人状态估计系统不会直接对完整状态做普通 EKF，而是会把状态拆成：

然后滤波器主要估计误差状态。

这就是 ESKF，误差状态卡尔曼滤波。

如果说 EKF 解决的是：

非线性系统怎么用卡尔曼滤波？

那么 ESKF 更进一步解决的是：

带姿态、IMU、旋转流形的机器人状态，怎么更稳定地用卡尔曼滤波？

这就是下一篇要讲的内容。

14. 小结

这一篇我们学习了 EKF，扩展卡尔曼滤波。

核心内容可以总结成：

  1. 标准 KF 适合线性系统；
  2. 真实机器人系统经常是非线性的；
  3. EKF 用非线性函数 \(f\) 描述状态预测；
  4. EKF 用非线性函数 \(h\) 描述观测预测；
  5. EKF 通过雅可比矩阵 \(F_k\)、\(H_k\) 在当前估计点附近做局部线性化；
  6. EKF 的流程仍然是预测和更新；
  7. EKF 的优点是能处理很多非线性机器人问题；
  8. EKF 的缺点是存在线性化误差、初值敏感、雅可比推导复杂等问题。

用一句话总结：

EKF 就是在非线性世界里，先用当前估计点附近的一小段“直线近似”，让卡尔曼滤波还能继续工作。

ESKF，误差状态卡尔曼滤波。
